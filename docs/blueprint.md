# **App Name**: LiveCast Studio

## Core Features:

- RTMP Broadcast: Encode and broadcast video streams directly to RTMP endpoints without a middle server.
- Guest Hosting: Allow hosts to invite guests to join the broadcast.
- Screen Sharing: Enable hosts and guests to share their screen during the broadcast.
- Focus Guest: Allow the host to highlight a specific guest's video feed as the main focus.
- Audio Control: Provide mute/unmute controls for both the host and guests.
- Camera Control: Enable hosts and guests to show/hide their camera feed.
- AI scene detection: Detect scene content, like camera vs shared screen vs presentation slides, so the LLM tool can add suitable lower-third banners or visual elements automatically

## Style Guidelines:

- Primary color: Deep purple (#673AB7) for a professional and modern look.
- Background color: Dark gray (#303030) for a sleek, focused interface.
- Accent color: Electric blue (#29B6F6) to highlight key controls and interactive elements.
- Body and headline font: 'Inter', sans-serif, for a clean, modern, and highly readable interface.
- Use clean, minimalist icons for controls and status indicators.
- Layout: Flexible grid layout to accommodate various screen sizes and participant configurations. Ensure key controls are easily accessible.
- Subtle transitions and animations to provide feedback and enhance user experience. For example, smooth transitions when focusing on a guest.
